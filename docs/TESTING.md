# Тестирование

ТЗ, раздел 5, п. 10; разделы 3.4 и 4.1.

## Автоматические тесты

| Набор | Сколько | Команда |
|---|---|---|
| Приложение (логика и экраны на 360dp) | 92 | `cd mobile && flutter test` |
| Анализатор Dart | — | `cd mobile && flutter analyze` |
| Сервер | 40 | `cd backend && pytest -v` |
| Справочники и карта контента совпадают с приложением | — | `python scripts/sync_from_mobile.py --check`, `python scripts/content_map.py --check` |

Всё это запускается в GitHub Actions на каждый push и pull request
(`.github/workflows/mobile-ci.yml`, `backend-ci.yml`). Релиз
(`release.yml`) не собирается, если тесты упали.

Что покрыто:

| Файл | Что проверяет |
|---|---|
| `economy_test.dart` | класс по возрасту, награды и лимит 2 задания в день, потолок опыта, огонёк, вклад 20 % (потолок 500), курсы, блок при голоде, продажа за 70 %, каталог, план бюджета, окно покупки, скрытый вход |
| `tz_scenario_test.dart` | первый запуск и сброс взрослым (шаги 1–3, 12), пункты ТЗ по номерам: история монеток, нехватка монет, рост от решений, срок цели по среднему, практика, словарик, сохранение, тестовый профиль, 5 периодов подряд, подарок взрослого, крупный шрифт |
| `level_up_test.dart` | новый уровень, монеты за рост, экран роста после дня |
| `day_paper_test.dart` | итоги дня: доход, траты питомца, копилка, рост |
| `pet_models_test.dart`, `pet_test.dart` | эмоции и стадии, модели на месте, перекраска, снятие с копилки, фильтр ника |
| `roads_test.dart` | дороги заданий, ошибка → «Повтори», родительский вход |
| `screens_test.dart`, `smoke_test.dart` | все вкладки на 360dp, тёмная тема, сохранение, подписи навигации |
| `glyphs_test.dart` | в текстах нет символов, которых нет в шрифте |
| `name_filter_test.dart` | мат и 18+ в нике и кличке |

## Тест-кейсы сквозного сценария (Приложение А ТЗ)

Для ручной проверки и живой демонстрации. «Авто» — тест, который
проверяет тот же шаг.

| № | Шаги | Ожидаемый результат | Авто |
|---|---|---|---|
| 1 | Установить APK, открыть | Финни здоровается, объясняет цель; на шаге правил — три решения: «надо», «хочу», копилка | `tz_scenario_test.dart` (шаги 1–3) |
| 2 | Ввести игровое имя, выбрать возраст | Мат не пропускается; настоящие имя, телефон, почта не спрашиваются | `tz_scenario_test.dart`, `pet_models_test.dart` (ник) |
| 3 | Выбрать вид и окраску (свайп), дать кличку | Питомец на главной в выбранном виде | `tz_scenario_test.dart` (шаги 1–3) |
| 4 | Посмотреть главную | Видны 60 🪙, питомец со статами, цель 0 / цена, задание «Решить» | `screens_test.dart` |
| 5 | «План»: разложить монеты на надо / хочу / копилку, «Подтвердить» | Больше бюджета не распределить, виден остаток; после подтверждения — «план / факт» | `economy_test.dart` |
| 6 | Решить задание верно и неверно | Верно: +10…25 🪙, разбор; неверно: разбор и «Повтори», монеты не отнимаются | `roads_test.dart` |
| 7 | «Магазин»: купить еду (надо) и игрушку (хочу); нажать на дорогой товар | Окно с ценой, категорией и пользой; «Купить / Отменить». Дорогой товар: «Не хватает N 🪙» и варианты | `economy_test.dart`, `tz_scenario_test.dart` |
| 8 | «Банк»: выбрать цель, отложить 10 | Накоплено и «осталось»; срок — по среднему пополнению; снятие — только после подтверждения | `tz_scenario_test.dart`, `pet_models_test.dart` |
| 9 | «Дневник» на главной | История: покупки, копилка, награды с суммами; итоги прошлого дня | `tz_scenario_test.dart` |
| 10 | «Следующий день» несколько раз | «Бумажка»: доход, траты питомца, ✅/❌ по решениям, опыт, совет; после серии дней — новый уровень, потом новая стадия | `level_up_test.dart`, `tz_scenario_test.dart` |
| 11 | Закрыть приложение (смахнуть), открыть | Всё на месте: день, монеты, копилка, цель, задания | `screens_test.dart`, `tz_scenario_test.dart` |
| 12 | Настройки → Родительский режим (примеры) → «Начать игру заново» | Подтверждение, затем онбординг с нуля | `tz_scenario_test.dart` (шаг 12), `roads_test.dart` (вход) |

Быстрый прогон для экспертов: Настройки → «Для экспертов» →
«Тестовый профиль с нуля», дальше «+1 день» / «+5 дней», «+1 уровень»,
«Исследователь» — без ожидания.

## Отчёт о проверке на физическом устройстве

ТЗ 3.1 требует проверить сборку хотя бы на одном телефоне с ОЗУ от 3 ГБ.
Эту часть заполняет команда после установки релизного APK.

| Параметр | Значение |
|---|---|
| Устройство, модель | _заполнить_ |
| Android, версия | _заполнить_ |
| ОЗУ | _заполнить_ (нужно ≥ 3 ГБ) |
| Сборка | `finny-v0.5.0.apk`, версия 0.5.0 (5) |
| Дата | _заполнить_ |

| Проверка | Цель ТЗ | Результат |
|---|---|---|
| Установка без среды разработки | 3.3 | _заполнить_ |
| Холодный запуск до главного экрана | ≤ 5 с | _замерить секундомером, 3 раза_ |
| Отклик на нажатие (покупка, «Дать», «Следующий день») | ≤ 1 с | _заполнить_ |
| Шаги 1–12 сценария без падений и тупиков | 3.4 | _заполнить_ |
| Прогресс сохраняется после закрытия | 2.5.13 | _заполнить_ |
| Работа в режиме полёта | 3.1 | _заполнить_ |
| Системный шрифт «крупный» | 3.6 | _заполнить_ |
| Анимации выключены в настройках | 3.6 | _заполнить_ |
