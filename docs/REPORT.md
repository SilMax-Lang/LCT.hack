## Что осталось команде (кодом не сделать)

1. **Проверка на физическом телефоне** с ОЗУ от 3 ГБ (ТЗ 3.1, 3.4):
   пройти шаги 1–12 и заполнить таблицу в [TESTING.md](TESTING.md).
2. **Замер холодного запуска** (≤ 5 с) там же. Риск: APK около 165 МБ
   из-за анимированных моделей. Если запуск медленный — собирать
   `--split-per-abi` и грузить модели по мере роста питомца.
3. **Ключ подписи релиза**: создать и добавить 4 секрета в GitHub —
   инструкция в [README](../README.md#подпись-релиза). Без ключа APK
   подписан debug-ключом: устанавливается, но для RuStore нужен свой.
4. **Скриншоты для RuStore** (не меньше трёх) — список в [RUSTORE.md](RUSTORE.md).
5. **Документ DOCX или PDF** (ТЗ 5): собрать из файлов `docs/`.
6. **Права на тексты заданий** из методичек — подтвердить
   ([DATA_AND_LICENSES.md](DATA_AND_LICENSES.md)).
7. Презентация и резервное видео демонстрации (ТЗ 4, 4.1).

## Важно при обновлении

приложением**: старую «Финни» (0.4.0 и раньше) нужно удалить, прогресс
в ней не перенесётся.
