# Дизайн питомцев: от картинки до живой анимации

Питомец — центр приложения: ребёнок видит, как его финансовые решения
отражаются на живом персонаже. Мы хотели, чтобы питомец ощущался «как
Говорящий Том»: дышал, моргал, радовался и грустил, а не был статичной
картинкой или эмодзи.

Этот документ описывает, как сделаны 27 анимированных моделей
(3 питомца × 3 окраски × 3 возраста), какие решения приняли и почему,
и как это воспроизвести. Скрипты лежат в [`tools/pets/`](../tools/pets/).

## Что получилось

| Питомец | Окраски | Возрасты | Состояния |
|---|---|---|---|
| Кошечка | рыжий, серый, чёрный | малыш, ученик, исследователь | `idle`, `happy`, `hungry` |
| Собачка | коричневый, рыжий, чёрный | малыш, ученик, исследователь | `idle`, `happy`, `hungry` |
| Енотик | рыжий, серый, ледяной | малыш, ученик, исследователь | `idle`, `happy`, `hungry` |

- `idle` — покой: дыхание, моргание, хвост покачивается; крутится по кругу.
- `happy` — радость: после еды, игрушки, верного ответа, нового уровня.
- `hungry` — грусть и голод: когда сытость, счастье или чистота низкие.

Каждый ролик — анимированный WebP 512×512 с прозрачным фоном, 12 кадров
в секунду, около 8 секунд, 1,5–2,5 МБ. Питомец меняется вместе с этапом
взросления: на новом этапе приложение подставляет модель другого возраста.

## Схема

```
Gemini (Nano Banana Pro)        базовая картинка: поза, стиль, зелёный фон 16:9
        │
Flow / Veo 3.1 Fast             видео 8 с, картинка = первый И последний кадр
        │
check_clip.py                   проверка ролика до обработки (брак не тратит время)
        │
pet_pipeline.py / batch_pets.py вырезка фона, общий кроп, петля, перекраска,
        │                        трекинг головы, точки склейки
        ▼
assets/pets/<вид>_<окраска>_<возраст>/
  idle.webp  happy.webp  hungry.webp  *_poster.png  pet.json
        │
PetView (lib/pet/pet_view.dart)  проигрывание, склейка роликов, аксессуары
```

## Шаг 1. Базовая картинка

Каждый ролик начинается и заканчивается одной и той же картинкой, поэтому
её ошибки переходят во все три состояния. Требования, к которым пришли:

- питомец стоит на задних лапах, передние у груди, смотрит в камеру —
  одинаковая поза у всех возрастов (к стоящему питомцу крепятся аксессуары);
- спокойная улыбка, рот закрыт, зубов не видно;
- питомец по центру, около 80% высоты кадра, до краёв далеко;
- однотонный зелёный фон `#00FF00` без тени и пола, и ни капли зелёного на
  самом питомце — иначе он вырежется вместе с фоном;
- ровно 16:9.

Сначала рисуется средний возраст по референсу стиля, из него — малыш
(голова ~50% тела, глаза крупнее) и взрослый (голова ~35%, длиннее лапы).
Правки делаются точечно: «измени только рот», новым чатом с одной картинкой.

## Шаг 2. Видео

Ролики делаются в Flow (Veo 3.1 Fast) режимом Frames to Video: базовая
картинка ставится **и первым, и последним кадром** — так ролик зацикливается
без скачка. Промпт состоит из общей части (персонаж не меняется, камера
неподвижна, фон ровный, питомец всегда стоит и не выходит за кадр) и блока
действия для состояния.

Чему научились на браке:

| Ошибка | Что происходит | Решение |
|---|---|---|
| Сравнение с другим животным («прыгает как зайчик») | кот превращается в зайца | в промпте только описание движения |
| Прыжки, резкие движения | Veo перерисовывает персонажа, лапы отрываются | только покачивание на месте, последняя секунда — возврат в позу |
| Картинка не 16:9 | чёрные полосы, петля прыгает | картинка ровно 16:9 |
| Агент Flow пересказал промпт | лишние действия | проверять запрос до «Одобрить», иначе «Отклонить» |
| Быстрый хвост | хвост размывается | «tail moves slowly» в промпте |
| Скачано в 720p | мало для качества | скачивать Upscaled 1080p |

Для экономии генераций Veo делал только одну окраску каждого питомца
(3 питомца × 3 возраста = 9 вариантов), остальные окраски получены
перекраской в скрипте.

## Шаг 3. Обработка (`tools/pets`)

`pet_pipeline.py` превращает ролики одного питомца в набор для приложения:

- **Фон.** Хромакей по зелёному + уточнение маски по краю
  (`refine_matte`), подавление зелёного отсвета на шерсти — без
  серо-бирюзовой каймы.
- **Общий кроп.** Все состояния одного питомца режутся одинаково, лапы на
  одной линии — при смене `idle` → `happy` модель не прыгает.
- **Петля.** В последних 15% ролика ищется кадр, ближайший к первому; ролик
  обрезается по нему — цикл без рывка.
- **Точки склейки (`cuts`).** Кадры, где питомец почти в базовой позе:
  в них приложение переключает ролики без скачка.
- **Трекинг головы (`track`).** Для каждого кадра — преобразование
  (поворот, масштаб, сдвиг) головы относительно кадра 0. Аксессуар,
  поставленный на голову в кадре 0, повторяет её движение.
- **Перекраска.** Шерсть проходит через карту градиента по яркости; глаза,
  нос, уши и рот сохраняются. Глаза защищены масками
  [SAM 2.1](https://github.com/facebookresearch/sam2) (Meta, Apache 2.0),
  которые ведут глаз по всем кадрам, включая прищур и моргание; без SAM —
  поиск глаз по цвету. `--qa` сохраняет кадры с найденными пятнами для
  проверки.
- **Сжатие.** WebP с альфа-каналом; для приложения пережато до q70 —
  те же кадры и тайминги, примерно на 20% легче.

`check_clip.py` проверяет исходный ролик до обработки: разрешение, чёрные
полосы, касание края, отрыв лап, мусор на фоне, расхождение первого и
последнего кадра.

## Шаг 4. В приложении

- Папка модели: `assets/pets/<вид>_<окраска>_<возраст>/`, её подбирает
  `PetAssets` по виду, окраске и этапу питомца.
- `PetView` проигрывает WebP по кадру (в памяти только текущий кадр),
  переключает ролики в точках склейки из `pet.json`, `happy` играет один раз
  и возвращается к циклу. Если ролика нет — играет `idle`, если нет модели —
  рисуется заглушка.
- Пока ролик грузится, показывается постер (`*_poster.png`). При системной
  настройке «убрать анимации» показывается только постер.
- Аксессуары — PNG поверх модели с точкой крепления в долях кадра; с
  `followHead` двигаются вместе с головой по трекингу.

## Как повторить

```bash
cd tools/pets
pip install -r requirements.txt
# один ролик — проверить до обработки
python check_clip.py idle.mp4 --sheet check.jpg
# вся папка исходников: <root>/<пет>/<расцветка>/<возраст>/видео/<state>.mp4
python batch_pets.py --root <папка исходников> --out ../../mobile/assets/pets --quality normal --qa
```

Подробнее о параметрах — [`tools/pets/README.md`](../tools/pets/README.md).
