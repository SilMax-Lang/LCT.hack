# Требования ТЗ и их выполнение

Выжимка обязательных требований технического задания и где они
выполнены в коде. Пути — относительно `mobile/lib/`, если не указано
иное. Подробности устройства — в [ARCHITECTURE.md](ARCHITECTURE.md),
механики — в [GAME_DESIGN.md](GAME_DESIGN.md).

Статус: ✅ выполнено, ⚠️ выполнено частично.

## Mobile

### Платформа и ограничения

| Требование | Статус | Как выполнено |
|---|---|---|
| Android 8.0+, портрет от 360dp | ✅ | `screenOrientation="portrait"`; тесты экранов на ширине 360dp |
| Локальное хранение | ✅ | `shared_preferences`, один JSON-сейв (`models/game_state.dart`) |
| Касаемые элементы ≥ 48×48dp | ✅ | `minimumSize` кнопок в `theme/kids_theme.dart`, чипы отделов высотой 48dp |
| Текст ≥ 16sp | ✅ | `KidsTheme._textTheme` поднимает мелкие стили |
| Состояние не только цветом | ✅ | статы с числом, ✅/❌ у ответов, «Надо» / «Хочу» текстом, эмодзи настроения |
| Запуск ≤ 5 с, отклик ≤ 1 с | ✅ | одна зависимость, без сети на старте; вспышка-отклик на действие 700 мс |
| Не запрашивать разрешения | ✅ | в `AndroidManifest.xml` нет разрешений |
| Игровой цикл офлайн, прогресс не теряется | ✅ | весь контент в APK, сеть не используется, сейв после каждого действия |

### Минимум контента

| Требование | Статус | В приложении |
|---|---|---|
| Питомец: 9+ визуальных комбинаций | ✅ | 3 вида × 3 окраски = 9; у котика — модели на 3 возраста × 3 эмоции (`models/pet.dart`, `assets/pets/`) |
| 3+ стадии роста | ✅ | Малыш, Ученик, Исследователь — уровни 1, 12, 35 (`Pet.stageOf`) |
| 5+ игровых периодов подряд | ✅ | число дней не ограничено («Следующий день» на главной) |
| 6+ заданий по 3 темам | ✅ | 35 заданий: математика (4 раздела) и финансы (3 раздела) — `data/lessons_data.dart` |
| 8+ покупок: 5 обязательных + 5 необязательных | ✅ | 44 позиции: 15 «Надо» (с миской, поилкой, лежанкой), 25 «Хочу» (игрушки и 20 украшений), 4 курса — `data/shop_data.dart` |
| 3+ цели накопления | ✅ | 6 готовых целей и своя цель — `data/goals_data.dart` |

### Правила логики

| Правило | Статус | Как выполнено |
|---|---|---|
| Отрицательный баланс запрещён | ⚠️ | проверки в `buyItem`, `buySkin`, `deposit`, `withdraw`; при нехватке кнопка покупки неактивна, но отдельного объяснения с вариантами действий нет |
| Снятие с накоплений — с подтверждением, новой суммой и сроком | ✅ | диалог в `screens/bank/bank_screen.dart` (`_withdraw`) |
| План бюджета редактируется до подтверждения, затем план / факт | ✅ | вкладка «План»: 4 корзины, шаг 5/10, «Подтвердить план», затем «план / факт» (`screens/plan/plan_screen.dart`, `GameState.changePlan/confirmPlan`) |
| Задания начисляют монеты, а не только очки | ✅ | `answerLesson`: 10–25 монет (не больше 2 заданий в день) и 5 XP |
| Ошибка создаёт временную задачу, а не сбрасывает прогресс | ✅ | неверный ответ → задание в `lessonsRetry` («Повтори») |

## Backend

Сервер по ТЗ **не обязателен**: обязательный сценарий полностью
работает офлайн, и мобильное приложение к серверу не обращается.
Сервер поднят как задел — раздача справочников и резервная копия
прогресса (см. [backend/README.md](../backend/README.md)).

| Требование | Как выполнено |
|---|---|
| Сервер организатором не предоставляется | свой: Docker-образ и Docker Compose (API + PostgreSQL) |
| Контент добавляется без изменения логики | в приложении — каталоги-константы в `data/`; на сервере — JSON-файлы в `backend/app/content/data/`, раздаются через `/api/v1/content/*` |
| Без сети прогресс не теряется | клиент — источник правды; сервер хранит только присланный снимок |
| Нет персональных данных | профиль на сервере адресуется UUID; в приложении данные только на устройстве |
