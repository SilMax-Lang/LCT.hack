# Требования из ТЗ (выжимка для разработки)

Источник — техническое задание конкурса. Полный контент (тексты заданий, товаров, целей, глоссарий) лежит в `4444.rtf` у аналитика. Здесь — то, что нужно держать перед глазами при реализации, чтобы не переспрашивать и не нарушить обязательные правила.

## Mobile

### Стек и лимиты

- Kotlin/Java нативно, или Flutter/React Native — выбор стека сам по себе не оценивается.
- Локальное хранение — Room/SQLite или эквивалент.
- Android 8.0+.
- Портретная ориентация от 360dp по ширине.
- Тач-таргеты — не меньше 48×48dp.
- Текст — не меньше 16sp.
- Запуск приложения — до 5 сек. Отклик на действие — до 1 сек.
- Разрешения (камера/микрофон/гео/контакты/bluetooth) — **не нужны**, не запрашивать.
- Игровой цикл работает **офлайн**. При отсутствии сети — сообщение об этом, **прогресс не теряется**.

### Обязательный минимум контента

- Питомец: 9+ визуальных комбинаций, 3+ стадии роста.
- 5+ игровых периодов подряд в демо-режиме.
- 6+ заданий по 3 темам (контент готов в `4444.rtf`).
- 8+ позиций покупок: 5 обязательных + 5 необязательных (готовы в `4444.rtf`).
- 3+ цели накопления (4 готовы в `4444.rtf`).

### Правила логики, которые нельзя нарушать

- **Отрицательный баланс запрещён.** При нехватке средств — объяснение и варианты действий, а не блокировка без причины.
- **Снятие с накоплений требует отдельного подтверждения.** До подтверждения показываем новую сумму и новый срок достижения цели.
- **План бюджета редактируется только до подтверждения.** После подтверждения — только сравнение план/факт, не редактирование.
- **Задания начисляют монеты, не только очки.**
- **Ошибка/провал создаёт временную игровую задачу**, не сбрасывает прогресс целиком.

## Backend

### Статус

Сервер **не обязателен** по ТЗ — обязательный сценарий полностью работает офлайн. Команда решила его поднять ради отдачи справочников (заданий, каталога, целей) через API — не потому что этого требует конкурс.

### Что важно учесть

- Организатор сервер не предоставляет — используем свой (Docker Compose, см. [backend/README.md](../backend/README.md)).
- Приложение должно работать без сети: если фича требует сеть — показываем «нет соединения», прогресс не теряем.
- Задания и каталог можно раздавать **и как конфиг-файл внутри APK, и через API** — оба варианта разрешены правилами конкурса. Главное: добавление нового контента не должно требовать изменения основной логики (не хардкодить количество/структуру заданий в коде).

### Контент готов к переносу в JSON/БД (источник — `4444.rtf`)

- 6 заданий: ситуация + варианты ответа + правильный ответ + объяснение.
- 10 товаров: 5 обязательных + 5 необязательных, у каждого цена и влияние на показатели питомца.
- 4 цели накопления: стоимость, срок, награда.
- Глоссарий терминов для справочного раздела.

Перед тем как проектировать JSON-схему этих сущностей (см. пример `PetState` в `backend/app/main.py`), сверьтесь с реальным содержимым `4444.rtf` — поля выше перечислены по смыслу, а не как готовая структура данных.
