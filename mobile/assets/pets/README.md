# Модели питомцев (анимированный WebP)

Сюда кладутся модели питомца. Код уже готов: как только файл появится,
приложение само покажет его вместо заглушки-эмодзи. Ничего в коде менять
не нужно, достаточно положить файл и пересобрать APK.

## Куда класть

```
assets/pets/<вид>/<образ>/<анимация>[_<этап>].webp
```

| Часть      | Значения |
|------------|----------|
| `вид`      | `cat`, `dog`, `penguin` |
| `образ`    | окраска `v1`, `v2`, `v3` **или** id скина (см. ниже) |
| `анимация` | `idle`, `happy`, `eat`, `sad`, `sleep` |
| `этап`     | необязательно: `baby` (ур. 1), `teen` (ур. 2), `adult` (ур. 3+) |

Примеры:

```
assets/pets/cat/v1/idle.webp          # рыжая кошечка, покой (любой этап)
assets/pets/cat/v1/happy_adult.webp   # рыжая взрослая кошечка радуется
assets/pets/dog/dog_chef/eat.webp     # собачка в скине «Повар» ест
```

## Какой файл выбирается

Для каждой ситуации приложение ищет файлы по порядку и берёт первый
найденный:

1. `<анимация>_<этап>.webp`
2. `<анимация>.webp`
3. `idle_<этап>.webp`
4. `idle.webp`
5. ничего нет → заглушка (эмодзи в цветном круге)

Значит, минимум для образа — **один `idle.webp`**. Остальные анимации можно
добавлять постепенно.

| Анимация | Когда играет |
|----------|--------------|
| `idle`   | всё время, пока ничего не происходит |
| `happy`  | после игрушки, наряда, верного ответа, на экране нового уровня |
| `eat`    | после еды из рюкзачка |
| `sad`    | когда сытость, счастье или чистота ≤ 20 |
| `sleep`  | после «Следующего дня» |

Реакции (`happy`, `eat`, `sleep`) играют ~1,4 с, потом модель возвращается
к `idle` или `sad`.

## Скины (id папок)

| Вид     | Скины |
|---------|-------|
| cat     | `cat_astronaut`, `cat_princess`, `cat_detective` |
| dog     | `dog_firefighter`, `dog_football`, `dog_chef` |
| penguin | `penguin_sailor`, `penguin_scientist`, `penguin_rockstar` |

Цены и названия скинов лежат в `lib/data/skins_data.dart`. Новый скин
добавляется так: запись в каталог, папка здесь и строка в `pubspec.yaml`
(секция `assets`).

## Требования к файлу

- Формат: **анимированный WebP** с прозрачным фоном, анимация зациклена.
- Размер кадра: **512×512 px**, квадрат. Питомец стоит по центру, лапы на
  нижних ~5 %: под моделью код рисует тень.
- Длительность цикла: `idle` 2–3 с; `happy`, `eat`, `sleep` около 1,5 с.
- Вес одного файла — желательно до 300 КБ (иначе раздуется APK).
- Одинаковый масштаб и положение во всех анимациях одного образа, чтобы
  модель не «прыгала» при смене анимации.

Прыжок, покачивание и значок реакции (💛, 😋, 💤) код рисует **поверх**
модели, в самой анимации их делать не нужно.

Файлы `.gitkeep` держат пустые папки в git. Когда в папке появится модель,
`.gitkeep` можно удалить.
