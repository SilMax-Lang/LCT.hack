# Модели питомцев

Одна модель — одна папка:

```
assets/pets/<вид>_<окраска>_<этап>/
  pet.json            описание роликов: кадры, скорость, точки склейки
  idle.webp           обычный      + idle_poster.png
  happy.webp          весёлый      + happy_poster.png
  hungry.webp         грустный     + hungry_poster.png
```

| Часть      | Значения |
|------------|----------|
| `вид`      | `cat`, `dog`, `penguin` |
| `окраска`  | `ginger` (v1), `gray` (v2), `black` (v3) |
| `этап`     | `small` — малыш, `medium` — подросток, `large` — взрослый |

Итого на вид: 3 окраски × 3 этапа = 9 папок, в каждой 3 эмоции.

## Что уже лежит

Котик и собачка: по 9 папок (`cat_*`, `dog_*`). У собачки папка
`ginger` — это окраска v1 «Шоколад», `gray` — v2 «Карамель», `black` — v3
«Уголёк»: имя папки идёт по номеру окраски, а не по цвету.
Пингвина пока нет — вместо них рисуется заглушка (эмодзи в
цветном круге). Как только папка появится, приложение само её подхватит.

## Когда что показывается

**Этап — по уровню питомца** (константы в `lib/models/pet.dart`):

| Уровень | Этап | Папка |
|---------|------|-------|
| 1–11    | малыш | `…_small` |
| 12–34   | подросток | `…_medium` |
| 35+     | взрослый | `…_large` |

**Эмоция — по счастью питомца:**

| Счастье | Эмоция | Ролик |
|---------|--------|-------|
| меньше 33 | грустный | `hungry` |
| 33–66   | обычный | `idle` |
| больше 66 | весёлый | `happy` |

**Анимация — только на главном экране.** Там играет ролик (`PetView`,
`lib/pet/pet_view.dart`): кадры декодируются по одному, ролики
переключаются в точках склейки из `pet.json`. На действие (еда, игрушка)
разово играет `happy`, потом возвращается ролик текущей эмоции.

Везде остальное — **постер** (`*_poster.png`): выбор вида и окраски
в начале игры, перекраска в магазине, экран нового уровня.

## Как добавить новый вид

1. Положить 9 папок `<вид>_<окраска>_<этап>/` с файлами как выше.
2. Добавить их в `pubspec.yaml` (секция `assets`).
3. Всё. Имена папок строит `PetAssets.folderFor`
   (`lib/services/pet_assets.dart`), тест `test/pet_models_test.dart`
   проверяет, что все файлы котика на месте.

## Требования к файлам

- Ролики — анимированный WebP 512×512, зациклены; постер — первый кадр
  ролика в PNG того же размера.
- Питомец в одном и том же месте кадра во всех роликах одной папки,
  иначе при смене эмоции он «прыгнет».
- `pet.json` генерируется вместе с роликами (кадры, `cuts` для склейки,
  `track` для аксессуаров по движению головы).
