# Финни — детский финансовый питомец 🐧

Игра для детей 7–11 лет: ребёнок заботится о питомце, выполняет задания,
ходит в магазин и откладывает монетки в копилку на мечту.
Помогает пингвинчик **Финни** — объясняет правила и подсказывает.

## Быстрый старт

Воркспейс-песочница была пустой, поэтому проект собран здесь с нуля
(только `lib/` + `pubspec.yaml` — платформенные папки `android/`, `ios/` и т.д.
берутся из твоего локального проекта).

**Вариант А — у тебя уже есть Flutter-проект (твой случай):**

```bash
cd <твой-проект>/mobile
# 1. Скопируй сюда lib/ и pubspec.yaml из этого воркспейса
# 2. Поставь зависимости и запусти:
flutter pub get
flutter run
```

**Вариант Б — с нуля:**

```bash
flutter create finny_app
cd finny_app
# скопируй lib/ и зависимости shared_preferences из pubspec.yaml сюда
flutter pub get
flutter run
```

Единственная внешняя зависимость: `shared_preferences` (сейвы профиля).

## Что реализовано (по ТЗ)

**Онбординг (6 шагов, `lib/screens/onboarding/`):**

| # | Экран | Файл |
|---|-------|------|
| 1 | Приветствие: машущий Финни + «Далее» | `welcome_screen.dart` |
| 2 | Имя игрока: макс. 15 символов, trim по краям, «Отлично!» | `nickname_screen.dart` |
| 3а | Вид питомца: кошечка / собачка / пингвинчик | `pet_type_screen.dart` |
| 3б | Окраска: 3 варианта на вид → **9 комбинаций** | `pet_color_screen.dart` |
| 4 | Имя питомца + кубик 🎲 (10 готовых имён) | `pet_name_screen.dart` |
| 5 | Три правила + «Понятно, давай играть!» | `rules_screen.dart` |

Свайп между шагами выключен — только кнопки (ребёнок не пропустит шаг).
Прогресс онбординга собирается в черновик и сохраняется **один раз** на финише.

**Кастомизация 3×3 = 9 комбинаций** (`lib/models/pet.dart` → `PetLook.of`):

| Вид | Вариант 1 | Вариант 2 | Вариант 3 |
|-----|-----------|-----------|-----------|
| 🐱 Кошечка | Рыжик 🟠 | Дымок 🌫️ | Снежок ⚪ |
| 🐶 Собачка | Шоколад 🟤 | Карамель 🍬 | Уголёк ⬛ |
| 🐧 Пингвинчик | Морячок 🔵 | Льдинка 🧊 | Пончик 🌸 |

**Главный экран** (`lib/screens/home/home_screen.dart`):
баланс 🪙 • уровень ⭐ • день 📅 • цель + накопления (есть/осталось/%) •
питомец с именем и этапом взросления 🌱→🌿→🌳 • сытость/счастье/чистота 100/100 •
шкала XP • подсказка Финни • активное задание • кнопка «Следующий день ➜».

**Механики из ТЗ:**
- Тап по питомцу → текстовая подсказка («…голоден!») + рюкзачок 🎒,
  предметы используются и прибавляют статы.
- Мягкие уведомления Финни: голод ≤40, половина цели, задание висит >1 периода.
- Переход периода: диалог «☀️ Новый день!» с начислением BaseIncome.
- Ежедневный бонус: «{имя} рад тебя видеть! +15 монет».
- Состояние дублируется текстом и эмодзи, а не только цветом.
- Прогресс сохраняется (SharedPreferences), в настройках есть «Начать заново».

**Навигация** (`lib/screens/main_shell.dart`, нижняя, 5 вкладок):
Питомец 🐾 • План 📋 • Задания ⭐ • Магазин 🛍️ • Банк 🐷.
Настройки — шестерёнка ⚙️ в AppBar (не занимает вкладку).

## Архитектура

```text
lib/
├── main.dart                  # точка входа: init GameState → runApp
├── app.dart                   # MaterialApp + GameStateScope (раздача состояния)
├── theme/kids_theme.dart      # детская Material3-тема
├── models/
│   ├── player_profile.dart    # никнейм
│   ├── pet.dart               # PetType × PetVariant, статы, этап, настроение
│   └── game_state.dart        # ВСЯ логика: деньги, цель, дни, магазин, сейвы
├── data/
│   ├── names_data.dart        # 10 имён для кубика
│   ├── shop_data.dart         # каталог: цены и эффекты предметов
│   └── quests_data.dart       # каталог заданий
├── widgets/                   # переиспользуемое: Финни, облачко, аватар, статы, кнопки
└── screens/
    ├── onboarding/            # 6 шагов + flow-контейнер на PageView
    ├── home/                  # главный экран
    ├── plan/ quests/ shop/ bank/ settings/
    └── main_shell.dart        # нижняя навигация (IndexedStack)
```

**Почему так:**
- Один `GameState extends ChangeNotifier` вместо кучи провайдеров —
  для MVP проще, а раздаётся через свой `InheritedNotifier` без пакетов.
- `models/` ничего не знают про экраны; `data/` — константы-каталоги,
  баланс игры правится в одном месте.
- Каждый экран — отдельная папка: легко добавлять (например, `wardrobe/`).

## Игровая экономика (стартовые цифры)

Старт: 60 монет. Доход за день: `40 + уровень × 10`.
Бонус за возвращение: +15. Траты дня: сытость −15, счастье −10, чистота −12.
Копилка/задания дают XP: 100 XP = новый уровень (и рост дохода).
Меняется в `game_state.dart`, цены — в `shop_data.dart`.
