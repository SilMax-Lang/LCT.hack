# Дизайн

Разделяем две вещи: **источник дизайна** (макеты, где дизайнер/аналитик рисует) и **готовые файлы**, которые реально нужны в проекте.

## Источник — Figma (не в git)

Макеты храним в Figma, ссылку впишите сюда:

> Figma: `<вставить ссылку на проект>`

`.fig`-файлы в git не кладём — это бинарный формат, гит не умеет показывать diff, только раздувает репозиторий. Ссылка на Figma и есть источник правды.

## Что реально лежит в этой папке

Только финальные экспортированные ассеты, которые нужны для сборки/публикации:

```
design/
├── icon/
│   └── icon-512.png        # иконка приложения 512x512 для карточки RuStore
├── screenshots/
│   ├── 01-onboarding.png
│   ├── 02-main.png
│   └── 03-budget.png
└── store-listing/
    └── feature-graphic.png # промо-баннер карточки (если требуется)
```

## Куда что уходит дальше

- **Иконка для самого приложения** (та, что видна на экране телефона) — не отсюда, а из `mobile/`: Flutter берёт иконку из `mobile/assets/icon/` и генерирует под все размеры через пакет [`flutter_launcher_icons`](https://pub.dev/packages/flutter_launcher_icons). В `design/icon/` лежит только исходник 512x512, из которого её делают.
- **Иконка и скриншоты для карточки RuStore** — грузятся вручную в консоль RuStore при публикации, они не собираются в APK. Держим их здесь, чтобы не потерять и не собирать заново перед каждой сдачей.
- Любые изображения, которые нужны **внутри** приложения (картинки питомца, иконки категорий и т.д.) — их место в `mobile/assets/images/`, а не здесь: так Flutter сможет их подключить как assets в `pubspec.yaml`.
