# Дизайн

UI/UX-схемы экранов (Figma-макеты, с учётом доступности) делает Максим. Финальные ассеты для приложения кладём сюда — то, что не помещается в Figma (иконка для RuStore, скриншоты).

Разделяем две вещи: **источник дизайна** (макеты в Figma) и **готовые файлы**, которые реально нужны в проекте.

## Требования к макетам (из ТЗ)

Точных px в ТЗ нет — макеты делаются в **dp/sp**, не в фиксированных пикселях, потому что у Android-экранов разная плотность. Figma не различает dp и px в самом инструменте (ставим фрейм 1:1 в dp-эквиваленте), разработчик учитывает это при переносе.

- **Базовый артборд**: 360×800dp (минимальная ширина по ТЗ, раздел 3.1) или 412×915dp (современный баланс) — ориентир для макетов.
- **Ориентация**: портретная — обязательна; поддержка планшетов и альбомной ориентации — плюс, не обязательное требование.
- **Доступность** (раздел 3.6 ТЗ):
  - интерактивные элементы — не меньше **48×48dp**
  - основной текст — не меньше **16sp**
  - состояние элемента нельзя передавать только цветом — контраст должен быть достаточным сам по себе (например, для disabled/error-состояний нужна ещё иконка/текст, не только цвет).

## Экспорт растровых ассетов

Для прототипа на хакатон хватает:
- **xxhdpi (3x, 480dpi)** — основной экспорт
- **xhdpi (2x)** — для более старых устройств
- mdpi и xxxhdpi — не нужны, экономим время

Иконки и иллюстрации лучше делать в **SVG** и растеризовать автоматически под нужную плотность (Flutter умеет из `.svg` через `flutter_svg`, либо экспорт из Figma сразу в нескольких плотностях), а не рисовать каждый размер вручную.

## Единственный фиксированный размер в px

Иконка приложения для карточки RuStore — **512×512px** (раздел 3.3 ТЗ), это единственное явное пиксельное требование во всём документе. Для скриншотов RuStore конкретный px не задан — берём как есть разрешение тестового устройства.

## Источник — Figma (не в git)

Макеты храним в Figma, ссылку впишите сюда:

> Figma: `<вставить ссылку на проект>`

`.fig`-файлы в git не кладём — это бинарный формат, гит не умеет показывать diff, только раздувает репозиторий. Ссылка на Figma и есть источник правды.

## Куда что уходит дальше

- **Иконка для самого приложения** (та, что видна на экране телефона) — не отсюда, а из `mobile/`: Flutter берёт иконку из `mobile/assets/icon/` и генерирует под все размеры через пакет [`flutter_launcher_icons`](https://pub.dev/packages/flutter_launcher_icons). В `design/icon/` лежит только исходник 512x512, из которого её делают.
- **Иконка и скриншоты для карточки RuStore** — грузятся вручную в консоль RuStore при публикации, они не собираются в APK. Держим их здесь, чтобы не потерять и не собирать заново перед каждой сдачей.
- Любые изображения, которые нужны **внутри** приложения (картинки питомца, иконки категорий и т.д.) — их место в `mobile/assets/images/`, а не здесь: так Flutter сможет их подключить как assets в `pubspec.yaml`.
