# Frontend (React + Vite + JavaScript)

Стек выбран специально под новичка: React — самая популярная библиотека, у неё больше всего бесплатных туториалов, ответов на Stack Overflow и видео на русском. Используем **JavaScript, не TypeScript** — на старте это лишняя сложность, добавите типы позже, когда будет время.

## Установка (один раз)

Нужен Node.js — скачать с https://nodejs.org (версия LTS). Проверить:

```bash
node -v
npm -v
```

## Запуск проекта

```bash
cd frontend
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173` — там сразу видно результат, страница обновляется автоматически при сохранении файла.

## Линт и сборка

```bash
npm run lint
npm run build
```

## С чего начать (бесплатный план обучения, без платных нейросетей)

### 1. Базы — если совсем с нуля (1-3 дня)
- **HTML/CSS/JS** — https://developer.mozilla.org/ru/docs/Learn (MDN, официальный бесплатный курс, на русском)
- Практика с сайтом целиком: **freeCodeCamp** — https://www.freecodecamp.org/ (английский, но интерфейс понятный, много практики)

### 2. React — официальная документация (лучший бесплатный источник)
- https://react.dev/learn — с 2023 года это лучший туториал по React, весь на понятном английском, с интерактивными примерами. Можно читать через переводчик браузера, если английский тяжело даётся.
- Русскоязычный курс по React с нуля (бесплатный, YouTube): канал **metanit** и канал **Timur Vafin** — ищите плейлисты "React для начинающих"

### 3. Практика именно на этом проекте
- Начните с малого: поменяйте текст в `src/App.jsx`, посмотрите как страница обновляется.
- Дальше — разбейте интерфейс на компоненты (кнопка, карточка, форма) — так React и задуман.
- Для запросов к бэкенду используйте `fetch()` (https://developer.mozilla.org/ru/docs/Web/API/Fetch_API/Using_Fetch) — бэкенд отдаёт `/health` и другие эндпоинты, спросите у бэкенд-разработчика адреса API.

### 4. Когда понадобится что-то готовое визуально (быстро для хакатона)
Не обязательно верстать всё руками — есть бесплатные библиотеки готовых компонентов:
- **Ant Design** — https://ant.design/ (много готовых форм, таблиц, кнопок)
- или проще: **Bootstrap** — https://getbootstrap.com/ (классический, самый документированный на русском)

### 5. Если что-то не работает
- Читайте текст ошибки в консоли браузера (F12 → Console) и в терминале — 90% ошибок React объясняют сами, что не так.
- Официальный FAQ и поиск по https://stackoverflow.com — почти любая ошибка React уже кем-то задавалась.
- Не нужно платных ИИ-инструментов: обычный поиск в Google/Яндексе по тексту ошибки + документация React решает почти всё.
