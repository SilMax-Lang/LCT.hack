# Финни — финансовая грамотность для детей через питомца

Команда **LitEnergy**.

«Финни» — Android-игра для детей 7–10+ лет. Ребёнок заводит питомца,
получает монетки за каждый игровой день и за решённые задания, покупает
питомцу еду и игрушки, откладывает в копилку на мечту. Так на практике
осваиваются базовые понятия: «надо» и «хочу», бюджет, накопления, цель.
Правила объясняет помощник Финни. Игра работает полностью офлайн,
персональных данных не собирает, к сети не обращается.

## Скачать APK

Готовая сборка — на странице
**[Releases](https://github.com/SilMax-Lang/LCT.hack/releases)**:
скачайте `.apk` из последнего релиза и установите на Android 8.0+
(понадобится разрешение «Установка из неизвестных источников»). Там же
лежит `.aab` для RuStore.

Пакет `ru.litenergy.finny`, версия **0.5.0** (сборка 5).

## Возможности

- **Питомец**: 3 вида × 3 окраски, 3 этапа (до 12 уровня Малыш,
  до 35 Ученик, дальше Исследователь) и 3 эмоции по счастью — у каждой
  комбинации своя модель; на главном экране она живая.
- **Игровые дни**: доход растёт с курсами, статы убывают, в конце дня —
  «бумажка» с итогами (доход, траты питомца, кошелёк, копилка) и ✅/❌ по
  трём решениям дня с советом на завтра.
- **Рост от решений**: опыт за день = 1 + 3 за каждое — питомец сыт и чист,
  план выполнен, монетки отложены (до 10), плюс 5 за задание; не больше 25
  в день. Под питомцем — почему он грустит и что поможет.
- **Задания — две дороги**: «Математика» (1–4 класс) и «Финансы»
  (3 уровня), всего 35 заданий. Уровень рекомендуется по возрасту (класс = возраст − 6),
  награда 10–25 монет не больше чем за 2 задания в день; ошибка
  ничего не отнимает, а превращается во временную задачу «Повтори».
  Плюс **«Практика в игре»** — 6 заданий-действий (план, копилка, покупки),
  которые засчитываются сами по настоящим действиям.
- **Магазин**: окно «Купить / Отменить», «Надо» (еда, уход, здоровье, миска/поилка/лежанка),
  «Хочу» (игрушки и коллекция из 20 украшений с продажей за 70 %), «Обучение»
  (курсы 20/40/80/160 поднимают доход 60/75/95/120), скидка дня, перекраска.
  Пока питомец голоден, игрушки и курсы закрыты. Не хватает монет —
  окно объясняет, сколько не хватает и что можно сделать.
- **План бюджета**: 4 корзины, шаги 5/10, подтверждение, затем «план / факт».
- **Копилка**: готовая или своя цель, вклад 20 % раз в 5 дней (не больше 500);
  срок до цели — по средней сумме пополнения; снятие — только после
  подтверждения с новой суммой и новым сроком.
- **Дневник**: история монеток за день (каждая покупка и награда с суммой),
  итоги прошлого дня, цель, рост, решённые задания. **«Как играть»** и
  словарик — в любой момент с главной.
- **Мотивация**: ежедневный бонус, «огонёк» — серия дней с действиями (+10 за 3 дня, +20 за 7),
  праздничный экран нового уровня.
- **Родительский режим** за проверкой «ты взрослый?»: чему учит игра,
  пройденные темы, прогресс, подарок +20 монет раз в день, смена возраста,
  сброс. **Режим эксперта** — кнопка «Для экспертов» в настройках (и скрыто —
  7 нажатий на «Версия…»): тестовый профиль с нуля, уровни, этапы, эмоции, дни.
- **Безопасность**: фильтр мата и 18+ в нике и кличке питомца,
  приложение не запрашивает никаких разрешений Android.
- Светлая и тёмная тема, текст от 16sp, кнопки от 48dp, портрет от 360dp,
  анимации отключаются в настройках, крупный системный шрифт поддерживается.

## Демонстрационный режим

1. Установить APK, пройти знакомство (или сразу шаг 2).
2. Настройки ⚙️ → «Для экспертов» → **«Тестовый профиль с нуля»**: Тестер,
   9 лет, рыжий котик; день 1, 60 монет. Повторное нажатие — сброс к началу.
3. Дальше сценарий идёт подряд, без ожидания: «Следующий день» на главной
   или «+1 день» / «+5 дней» в режиме эксперта; «+1 уровень», «Ученик»,
   «Исследователь», эмоции — там же.
4. Сброс «как у родителя»: Настройки → «Родительский режим» → «Начать игру
   заново».

Пошаговые тест-кейсы сценария — [docs/TESTING.md](docs/TESTING.md).

## Быстрый старт (локально)

Нужно: [Flutter SDK](https://docs.flutter.dev/get-started/install)
(канал stable, 3.44+; проверено на 3.47), JDK 17, Android SDK (API 36)
и Android-эмулятор или телефон с включённой отладкой по USB. Проверить
окружение — `flutter doctor`.

```bash
git clone https://github.com/SilMax-Lang/LCT.hack.git
cd LCT.hack/mobile
flutter pub get
flutter run
```

### Сборка релиза

```bash
cd mobile
flutter build apk --release        # mobile/build/app/outputs/flutter-apk/app-release.apk
flutter build appbundle --release  # mobile/build/app/outputs/bundle/release/app-release.aab
```

В GitHub релиз собирается сам: тег `v*` или ручной запуск
«Release APK» на вкладке Actions (поле `tag`, например `v0.5.0`).

### Подпись релиза

Ключа подписи в репозитории нет (ТЗ 3.4). Один раз создать ключ:

```bash
keytool -genkey -v -keystore finny-release.jks -keyalg RSA -keysize 2048 \
  -validity 10000 -alias finny
```

- **Локально:** положить рядом файл `mobile/android/key.properties`
  (он в `.gitignore`):
  ```properties
  storeFile=/полный/путь/finny-release.jks
  storePassword=...
  keyAlias=finny
  keyPassword=...
  ```
- **В GitHub:** Settings → Secrets → Actions: `FINNY_KEYSTORE_BASE64`
  (`base64 -w0 finny-release.jks`), `FINNY_KEYSTORE_PASSWORD`,
  `FINNY_KEY_ALIAS`, `FINNY_KEY_PASSWORD`.

Без ключа релиз подписывается debug-ключом — ставится, но для RuStore
нужен свой ключ. Ключ хранить в надёжном месте: без него нельзя выпустить
обновление.

Сервер для игры **не нужен**: весь контент зашит в приложение, прогресс
хранится на устройстве. Необязательный сервер (справочники и резервная
копия прогресса, Swagger UI на `/docs`) запускается отдельно —
см. [backend/README.md](backend/README.md).

## Тесты

```bash
cd mobile
flutter analyze
flutter test
```

92 теста приложения: логика экономики и роста, экраны на ширине 360dp,
сквозной сценарий ТЗ по шагам. Тест-кейсы для ручной проверки —
[docs/TESTING.md](docs/TESTING.md).

Сервер: `pytest -v` и `ruff check .` в папке `backend/` (подробнее —
в [backend/README.md](backend/README.md)). Оба набора автоматически
прогоняются в CI на каждый push и pull request
([.github/workflows](.github/workflows)).
